- **Windows HDR: `App::hdr` draws a window in scRGB.** With `Hdr::Auto`, a window on a display Windows has in HDR mode draws into an `Rgba16Float` swap chain in `DXGI_COLOR_SPACE_RGB_FULL_G10_NONE_P709` (linear, 1.0 at 80 nits, unclamped), blending in linear light; SDR colours (fills, text, images, SDR video, the clear colour) are drawn once at the display's SDR content brightness, while scRGB native surfaces and layer composites go through as they are. It follows the window between displays (`WM_DISPLAYCHANGE`, `WM_SETTINGCHANGE`, moves, focus), `WindowHandle::set_hdr` switches it while running, and `RUNE_HDR=1`/`0`/`auto` override it. Off by default: windows without it draw as before. `SharedTexture::format(SharedFormat::Rgba16Float)` takes FP16 scRGB frames (`Transfer::ScRgbLinear`) with an optional `ready_fence`; `Renderer::set_format` no longer turns on sRGB blending for `Rgba16Float`. `examples/hdr_verify` checks it all end to end on the GPU.
